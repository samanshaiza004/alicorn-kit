<div class="lede">
AliKit is an optional companion library for <a href="https://github.com/Carnival-Science/Alicorn">Alicorn</a>,
the native GUI runtime for Odin. Every component is ordinary Odin source over Alicorn's public
UI, semantics, layout, and input APIs. There is no second UI tree, state store, theme engine, or
component lifecycle.
</div>

## Native previews, not recreations

These are genuine SDL_GPU windows captured from the examples in this repository. The site does
not reimplement a component in HTML or JavaScript. Interactive WebGPU previews are a later
catalog step; the capture and the copyable source are the v1 contract.

## How to read a component page

Every page follows the same order so the five-point Alicorn authoring standard stays inspectable:

| Five-point standard | Where it appears |
| --- | --- |
| Complete, copyable implementation | **Copyable implementation** |
| Individually composable parts | **Parts and identities** |
| Custom styling and motion | **Styling, motion, and theme** |
| Keyboard and accessibility contracts | **Keyboard and accessibility contract** |
| `testui` conformance examples | **Conformance tests** |

Each page also lists the public API, known limits, the exact Alicorn pin used for the capture,
and a source map back to the package, tests, example, and theme data. The
[Alicorn component-authoring standard](https://github.com/Carnival-Science/Alicorn/blob/master/docs/component-authoring.md)
is the upstream reference for the split between Alicorn, AliKit, and the application.

## Pin the pair together

<div class="pin-note">
<strong>Source-level and early.</strong> AliKit imports Alicorn's public packages and may evolve
with them. Consume the exact Alicorn revision recorded in
<a href="https://github.com/samanshaiza004/alicorn-kit/blob/main/dependencies.lock.json"><code>dependencies.lock.json</code></a>
(<code>47c9d4a7cd1f637876190fec899daeeac00a30ae</code> at the time of this catalog). The
<a href="compatibility/">compatibility page</a> and the
<a href="manifest/">machine-readable registry</a> record the same pin.
</div>

## Not in AliKit yet

Calendars, color pickers, split panes, terminals, and rich editors are not components here. The
P0 table is non-spanned. Built-in sorting, filtering, and editing are application policy. A
nested tree sidebar is a later Sidebar variant. Add a component only when a real application
need demonstrates reusable behavior.
