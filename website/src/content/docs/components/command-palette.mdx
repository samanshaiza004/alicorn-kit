<div class="lede">
<code>alikit:command_palette</code> provides a themed modal palette for searching and activating a
caller-owned action list. The application owns command discovery, stable IDs, ranking policy, and
dispatch; AliKit owns the palette interaction, presentation, and focus restoration. The component
re-exports `Item`, `Item_ID`, and `Match`, so consumers can use its public input and result APIs
without importing model types. Import `palette_model` only when using its independent helpers.
</div>

## Examples

Start with the [minimal Quick Start](https://github.com/samanshaiza004/alicorn-kit/blob/main/examples/command_palette_quick_start/main.odin): it uses the stock palette with two caller-owned actions and needs only `alicorn:ui` and `alikit:command_palette`.

The separate [reference application](https://github.com/samanshaiza004/alicorn-kit/blob/main/examples/command_palette/main.odin) runs with `--reference` to show the full Northstar workspace scene and prefill its query with `export`. Its visual target is the authored [Command Palette SVG](https://github.com/samanshaiza004/alicorn-kit/blob/main/docs/research/authoring-reliability/references/command-palette.svg); this page does not embed desktop application screenshots.

The reference test checks the modal's 660 × 576 logical bounds at 1280 × 800, 960 × 720, and 760 × 640, plus query/result visibility, containment, filtering, selection semantics, activation, and focus restoration. TestUI observes retained text and geometry, not GPU pixels. Native pixel matching and DPI captures remain unverified.

## Responsibility split

| Layer | Responsibility |
| --- | --- |
| **Alicorn** | Modal overlay, focus scope, input routing, text field, virtual list, semantics, layout, and rendering. |
| **`command_palette`** | Controlled query, cached match buffer, selection by stable ID, keyboard/pointer routing, panel appearance, and focus restoration. |
| **Application** | Items and stable `Item_ID` values, matching/ranking policy in caller-filtered mode, open shortcut, and activation dispatch. |

The compact `build` path owns its overlay and default row drawing. The reference scene composes the public query and result-list parts so it can add per-item icons and keyboard shortcuts. `Item` has no icon or shortcut fields, and `build` does not currently accept a custom-row callback, so the example maps each stable item ID to those presentation values.

That custom shell imports `alicorn:runtime` for `modal_overlay_begin/end` and `semantic_describe_as`. Those public operations are not re-exported by `alicorn:ui`; the minimal `build` example below needs only `alicorn:ui` and `alikit:command_palette`.

Use the palette for command access. Do not use it as a general dialog, a file picker, or a router:
those are application or other-component concerns.

## Package example and source-copy recipe

Production source closure: `command_palette/command_palette.odin`,
`palette_model/model.odin`, `palette_parts/parts.odin`. The complete recipe is in
[`components.json`](https://github.com/samanshaiza004/alicorn-kit/blob/main/components.json);
place copied files in sibling packages and apply its `importRewrites`. No AliKit
collection is required; native builds still use Alicorn’s pinned AccessKit compiler
arguments. Tests and examples remain in AliKit. The import snippet below shows ordinary
collection-based package use.


```odin
import ui "alicorn:ui"
import palette "alikit:command_palette"

SAMPLE_ITEMS :: [2]palette.Item{
	{id=palette.Item_ID(1), title="Open File", description="Browse the workspace"},
	{id=palette.Item_ID(2), title="Build Project", keywords="compile"},
}

App :: struct {
	palette_state: palette.State,
	items:   [2]palette.Item,
}

render :: proc(app: ^App, ctx: ^ui.UI) {
	_ = ui.text(ctx, "AliKit · Command Palette", size=24)
}

render_overlays :: proc(app: ^App, ctx: ^ui.UI) {
	if !app.palette_state.open { return }
	event := palette.build(ctx, &app.palette_state, app.items[:],
		ui.key_string("app-palette"),
		palette.Options{title="Example Actions"})
	if event.kind == .Activated {
		// Dispatch the stable ID in application code.
	}
}

on_key :: proc(app: ^App, rt: ^ui.Runtime, key: ui.Application_Key) -> bool {
	if !app.palette_state.open && key == .Open_Command_Palette {
		return palette.open_palette(&app.palette_state, rt)
	}
	return false
}

main :: proc() {
	app := App{items=SAMPLE_ITEMS}
	if !palette.init(&app.palette_state) { return }
	defer palette.destroy(&app.palette_state)
	ui.run(&app, render,
		title="AliKit Command Palette",
		width=760,
		height=520,
		on_key=on_key,
		render_overlays=render_overlays,
	)
}
```

`init` takes the allocator that owns the query and match buffer; `destroy` releases them.
`open_palette` clears the query, captures the current focus, and requests a redraw. If the reset
fails, the palette stays closed and `state.last_status` reports the reason. If the match buffer
cannot grow, the old buffer remains valid and the modal shows
`Options.allocation_error_message`.

## Parts and identities

| Part | Identity | What can be replaced |
| --- | --- | --- |
| Modal overlay | `State.overlay_node` | Backdrop color, padding, and panel appearance through `Options.appearance`. |
| Panel | `State.panel_node` | Shape, material, physical height, fill, and gap. |
| Title and query | stable child keys | Title visibility, prefix, height, and text style. |
| Query input | `input` part | Controlled query field with an accessible name. |
| Result list | `list_begin`/`list_end` | Virtual list height, row height, and accessible name (`results_accessible_name`). |
| Result row | stable `Item_ID` | `item_begin`/`item_end` owns `List_Box_Option`; the author may draw custom content. |
| Groups | `group_begin`/`group_end` | Optional single-level semantic group for short, fully realized result sets. |
| Empty | `empty` | Configurable empty message. |
| Footer | stable footer key | Footer label text. |

`build` is now a shell over the same public parts as `alikit:palette_parts`:
`input`, `list_begin`, `item_begin`, `item_end`, `empty`, `group_begin`, and
`list_end`. The application can own its own modal/shell and still use those
parts, or call `build` for the complete modal. Three examples cover the paths:
the default modal (`examples/command_palette`), an application-owned shell with
custom rows and groups (`examples/command_palette_parts`), and a palette +
Segmented search scope (`examples/command_palette_composition`).

Selection is retained by `Item_ID`, not row index. If the selected item disappears, becomes
disabled, or stops matching, selection moves to the first enabled result. Disabled items stay
visible but cannot be selected or activated.

## Styling, motion, and theme

The default appearance uses Alicorn's `Surface` role and a neutral backdrop. Applications may
enable `Options.appearance`:

| `Appearance` field | Effect |
| --- | --- |
| `overlay_padding`, `panel_padding`, `panel_gap` | Space around and inside the modal. |
| `backdrop_color`, `backdrop_effect` | Modal backdrop treatment. |
| `panel_shape`, `panel_material`, `physical_height`, `panel_fill` | Panel surface. |

The component registers no theme resources. Borrowed appearance values apply to the current
build only. `Options.hide_title`, `query_prefix`, `query_height`, and `query_text_style` match an
existing palette header without replacing the controlled query field.

The palette currently has no component-authored motion. Alicorn's modal overlay and control
recipes own focus/hover presentation; keep application motion outside the palette shell.

## Keyboard and accessibility contract

| Input | Result |
| --- | --- |
| `Ctrl+Shift+P` | The canonical host shortcut maps to `.Open_Command_Palette`; the application decides whether to open. |
| `Up` / `Down` | Move selection through enabled, matching results. |
| `Home` / `End` | Move to the first/last enabled result. |
| `Return` | Emit one activation event with the selected stable `Item_ID`. |
| `Escape` | Close the palette; native composition handling runs first. |
| pointer | Row activation through the ordinary Button owner; outside click dismisses through the modal scope. |

- While the query field reports active composition, the palette declines `Up`, `Down`, and
  `Return` so the native text host can handle them.
- The modal retains Alicorn's focus scope, hit testing, and accessibility behavior. On close,
  focus returns to the captured opener.
- Selection is published on the list and rows. Activation is one event; the application applies
  its own command and error policy.
- Not claimed: Unicode case folding, fuzzy ranking, command registration, application dispatch,
  or a native OS command service.

## Conformance tests

`command_palette/command_palette_test.odin` drives the package through `alicorn:testui` and
covers:

- substring matching, caller-filtered order, disabled skipping, and selection reconciliation
  after removal or reorder;
- open/close, query reset failures, match-buffer allocation failures, and status reporting;
- pointer, keyboard, and semantic activation producing the same stable-ID event;
- focus capture and restoration, modal containment, and Escape dismissal;
- the `.Modal_Dialog` pattern check with a positive run and a negative control that fails at a
  named step;
- idle return after the palette closes.

`command_palette/visual_output_test.odin` exercises the reference shell at all
three logical viewports. `palette_parts/parts_test.odin` also checks that the
default result title has visible shaped text after `row_surface` fills its
Button owner.

```powershell
odin test command_palette -collection:alicorn=<alicorn> -collection:alikit=.
./out/command_palette_example.exe --smoke
```

Headless coverage does not validate the operating system's IME candidate window, a physical
screen-reader session, or pixels. Native smoke runs SDL_GPU D3D12 startup and one submitted
frame.

## API reference

| Declaration | Notes |
| --- | --- |
| `State` | Controlled query buffer, cached match buffer, selection, focus/restoration flags, and `last_status`. Zero-initialize; call `init` before use. |
| `Options` | `title`, `query_accessible_name`, `empty_message`, `allocation_error_message`, `footer_label`, `query_prefix`, `hide_title`, panel/list/row/query geometry, and `query_text_style`. |
| `Appearance` | Optional surface overrides; `enabled=false` keeps Alicorn defaults. |
| `Event` / `Event_Kind` | One-shot `Activated` event carrying `item_id`. |
| `Search_Mode` | `Substring` (built-in) or `Caller_Filtered` (application supplies the ranked slice). |
| `Status` | `Ready`, `Query_Reset_Failed`, `Query_Update_Failed`, `Match_Buffer_Allocation_Failed`. |
| `init` / `destroy` | Allocate and release the query and match buffer. |
| `open_palette` / `close_palette` | Controlled open/close with focus capture and restoration. |
| `build` | Describe the modal; call from `render_overlays` after the ordinary root. |
| `input`, `list_begin`, `item_begin`, `item_end`, `empty`, `group_begin`, `group_end`, `list_end` | Public result/shell parts. |
| `Result_List`, `Result_Row`, `Result_Group`, `result_row_key` | Result contexts and retained row key. |
| `handle_key`, `text_change`, `pointer`, `after_frame` | Lower-level host path when not using `ui.run` scoping. |
| `set_query`, `query_text` | Controlled query value for caller-filtered ranking. |

## Limits

- Built-in matching is ASCII case-insensitive substring search. Non-ASCII UTF-8 bytes compare
  exactly; Unicode case folding and fuzzy ranking remain application policy.
- The palette does not register commands, choose ranking, or perform application dispatch.
- The lower-level path requires the application to describe the root first, then `build`, then
  `after_frame` after `alicorn.end_frame`.
- Headless tests do not prove native IME navigation or a platform accessibility bridge.
