# Condition D trial artifacts

This folder archives one isolated reproduction trial per reference component,
completed on 2026-11-27 with the current API, component guide, layout cookbook,
and TestUI layout assertions. Each folder contains the generated Odin source
and a trial log. Build outputs and screenshots are intentionally omitted.

These are replication artifacts, not a success-rate comparison. The protocol
requires at least three independent trials per component and condition, fixed
prompts and budgets, and a matched historical baseline. The current batch does
not meet those requirements. None of these archived trials received native
pixel or physical-DPI review.

Earlier Palette and Data Grid attempts from the same date were exploratory and
are excluded from the replication count: their authors consulted existing
component tests or research material outside the assigned trial inputs. Only
the clean trials archived here count toward the one-per-reference total.

The trial notes identify dependency revisions and the local macOS compiler and
collection paths used. Replace those machine-specific roots when reproducing
the commands on another machine.
