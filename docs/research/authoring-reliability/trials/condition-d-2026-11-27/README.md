# Condition D trial artifacts

This folder archives two independent Condition D batches for the three
reference components. The first batch is at the folder root; the curated second
batch is in [`replication-2/`](replication-2/). Both used the current API,
component guide, layout cookbook, and TestUI layout assertions. Each trial
contains generated Odin source and a trial log. Build outputs and screenshots
are intentionally omitted.

These are replication artifacts, not a success-rate comparison. Two clean
Condition D trials per component do not meet the protocol's minimum of three
trials per condition, and Conditions A/B/C still lack matched replications.
There is no AI-authoring superiority claim. None of the archived trials
received native pixel or physical-DPI review.

Earlier Palette and Data Grid attempts from the same date were exploratory and
are excluded from the replication count: their authors consulted existing
component tests or research material outside the assigned trial inputs. Only
the clean trials archived here count toward the two-per-reference total.

The trial notes identify dependency revisions and the local macOS compiler and
collection paths used. Replace those machine-specific roots when reproducing
the commands on another machine.
